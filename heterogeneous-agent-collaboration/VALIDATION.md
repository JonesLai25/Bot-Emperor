# 驗證狀態

槓鈴式智慧資源配置為 EXPERIMENTAL。候選 PBT：生成多層派工樹、已證實的資源等級與推理強度；觀測全部新建節點，任何等於主智能體等級的節點均為反例，包括間接派工與強度變更；配置未知時不得判為符合。合法的低成本或高能力節點不應被拒絕。保持等級與能力條件不變而更換名稱或供應商，判定應不變；原有責任、授權與驗收條件不得降低。生成器不得向獨立 oracle 提供預期標籤，失敗序列應保留及縮減。此為設計，尚未執行，不能證明真實任務效益。

Experimental BIA properties: generate multilevel delegation trees with verified resource tiers and reasoning efforts; inspect every created agent. Any agent at the lead's tier is a counterexample, including indirect delegation or a different effort; unknown configuration cannot pass. Permit valid lower-cost and higher-capability agents. Renaming models or providers while retaining tier and capability must preserve the result; responsibility, authorization and acceptance remain intact. Keep generator labels from an independently specified oracle and retain and shrink failures. This is an unexecuted design, not evidence of real-world benefit.
